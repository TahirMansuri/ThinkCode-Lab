Privacy Policy

ThinkCode Lab

Effective Date: November 4, 2026

Developer: Tahir Mansuri (InfoGalaxy / Department of Computer Applications)

Summary

ThinkCode Lab is built with a strict offline-first, privacy-by-design principle. We do not collect, store, sell, or transmit any personal data, usage metrics, or code from your device.

1. Information We Collect

Zero Personal Data Collection: ThinkCode Lab does not require an account, sign-in, email address, phone number, or payment information. You can use all features of the application completely anonymously.

2. Execution & Data Storage

All programming language engines (Python, PHP, Oracle SQL, JavaScript, HTML/CSS, Linux Shell) run entirely on your local device inside client-side WebAssembly sandboxes.

  • Your code, scripts, databases, and input history remain strictly stored on your own device (via local browser storage / app sandboxed filesystem).
  • No code or SQL queries are sent to external servers or cloud services.

3. Third-Party Services and Analytics

ThinkCode Lab contains zero third-party tracking libraries, zero ad networks, and zero telemetry. No data is shared with third parties.

4. Permissions

The Android application only requests standard permissions strictly necessary for local file operations (saving your code files or exporting SQL scripts to your device storage when you explicitly click Save/Export).

5. Children's Privacy

ThinkCode Lab is designed for educational use by students of all ages. Because we do not collect any personal data from any user, we comply fully with COPPA and global children's data privacy regulations.
